# PCB

A custom board to replace the XIAO dev board once the design settles (M6), for a
much slimmer pendant. Designed in KiCad.

Not started. The board carries the ESP32-S3, the camera connector, the PDM
microphone, the tap input, the status LED, battery charging, and power
management tuned for aggressive camera sleep. The firmware's board-config is the
only software change when moving from the dev board to this one.
