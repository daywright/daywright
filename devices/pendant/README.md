# Daywright Pendant

The wearable device (M5): a necklace with a microphone and a camera, and a hidden
earpiece driven by the phone. A tap addresses it, so there is no wake word in
public (ADR-0007).

- `firmware/`: XIAO ESP32-S3 Sense firmware (ADR-0006).
- `hardware/`: the enclosure (`enclosure/`) and the later custom board (`pcb/`).
